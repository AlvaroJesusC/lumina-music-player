# Reglas y Estándares para Antigravity AI en lumina_player

Consulta las directrices completas y obligatorias en [AGENTS.md](file:///C:/Users/AlvaroJ/Documents/AndroidProjects/lumina_player/AGENTS.md).

Este proyecto cuenta con 40 skills especializadas instaladas en `.agent/skills/`.
Siempre que el usuario pida crear, optimizar o modificar código:
1. **Optimización y Rendimiento de Audio (60/120 FPS):** Aplica rigurosamente `.agent/skills/flutter-performance/SKILL.md`.
2. **Mejora de UI y Layout:** Aplica `.agent/skills/adaptive-layout/SKILL.md`, `.agent/skills/widget-composition/SKILL.md`, `.agent/skills/motion-and-haptics/SKILL.md` y `.agent/skills/design-system-structure/SKILL.md`.
3. **Código Limpio y Moderno:** Aplica `.agent/skills/dart3-idioms-and-coding-standards/SKILL.md` y `.agent/skills/async-safety/SKILL.md`.
